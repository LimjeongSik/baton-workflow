# AI 티 점검표

계획 단계와 구현 뒤에 각각 한 번씩 확인한다.

**이 점검표는 남과 달라 보이게 하려는 목록이 아니라, 이유 없이 기본값을 반복한 선택을 찾는 목록이다.** 같은 모서리 반경, 가운뎃점, 흰 배경, 익숙한 문구 자체는 문제가 아니다. 다음 둘 중 하나일 때만 걸린 것으로 본다:

- **이유가 없다:** 주제·사용자·분야 관례·디자인 시스템·사용자가 고른 방향 중 어디서도 설명할 수 없고, 다른 주제의 화면에서도 똑같이 나왔을 선택이다
- **해친다:** 그 선택 때문에 정보 위계, 과업 흐름, 가독성, 대비가 나빠진다

분야 관례(예: 대시보드의 표, 앱의 탭 바), 기존 디자인 시스템, 사용자가 고른 레퍼런스에서 나온 선택은 걸린 것이 아니다 (`priorities.md`). 걸린 항목을 고칠 때도 "다르게 보이게"가 아니라 "이유가 있게" 고친다.

frontend-design 스킬이 꼽은 기본값(크림+세리프+테라코타, 검정+형광 강조, 신문형 레이아웃, SaaS 카드 키트, 대문자 eyebrow·가운뎃점·`→` 같은 템플릿 장식)도 같은 기준으로 확인한다.

## 컬러

- [ ] 다크·네이비·슬레이트 배경을 썼는데, 요청·분야 관례·사용 환경(어두운 곳에서 오래 봄 등)에서 나온 이유가 없다
- [ ] 강조색(인디고·보라·일렉트릭 블루 등)이 주제와 관계없이 "흔히 쓰니까" 골라졌다
- [ ] 그라데이션이 의미(진행, 깊이, 브랜드 자산) 없이 장식으로만 쓰였다
- [ ] Tailwind 기본 팔레트 값을 손대지 않고 썼는데, 프로젝트가 Tailwind 기본값을 시스템으로 쓰는 것도 아니다
- [ ] 중립색이 주조색과 관계없이 정해져서 화면 전체의 온도가 따로 논다
- [ ] 강조색이 여러 곳에 칠해져서 정말 중요한 행동·상태가 눈에 띄지 않는다
- [ ] 팔레트의 어떤 색에 "왜 이 주제에 이 색인가"를 한 줄로 설명할 수 없다

## 레이아웃·형태

- [ ] 내용의 종류와 중요도가 다른데 모두 같은 크기·같은 모양의 카드에 들어 있어서, 무엇이 먼저인지 읽히지 않는다
- [ ] 모서리 반경·그림자·테두리를 모든 요소에 같게 처리해서 면이 어디서 나뉘고 무엇이 위에 있는지 구분되지 않는다 (같은 값을 체계적으로 쓰는 것 자체는 괜찮다)
- [ ] 같은 열 수의 그리드가 내용과 관계없이 반복되어, 섹션마다 무엇이 다른지 보이지 않는다
- [ ] 읽기 흐름상 왼쪽 정렬이 나은 내용(목록, 긴 문장, 표)까지 가운데 정렬이다
- [ ] 글래스모피즘, 네온 글로우, 장식용 블롭이 정보 전달 없이 들어가 있고 대비나 가독성을 떨어뜨린다

## 타이포

- [ ] 서체를 고른 이유가 없다. 주제·분야·사용 환경과의 관계를 한 줄로 말할 수 없다 (특히 랜딩·브랜드 화면에서 한글 산세리프 하나로 전부를 처리)
- [ ] 큰 제목이 800 이상 굵기에 `-0.03em` 같은 큰 음수 자간, `1.2` 안팎의 좁은 행간이다. 한글 글자가 뭉치고, 주제와 관계없이 생성형 화면과 같은 인상이 난다
- [ ] 굵기를 제목 800 · 본문 400 · 나머지 600으로, 이유 없이 기계적으로 나눴다
- [ ] 헤드라인의 한 단어만 색·이탤릭·굵기로 강조했는데, 그 단어가 정말 핵심이라는 이유가 없다
- [ ] 제목마다 위에 대문자 라벨(eyebrow)이 붙어 있는데, 그 라벨이 탐색이나 분류에 도움이 되지 않는다
- [ ] 크기·굵기 대비가 약해서 위계가 안 보인다 (예: 모든 글자가 14~18px에 몰려 있음)
- [ ] 히어로 제목만 64px 넘게 거대하고 나머지는 모두 비슷한 크기라, 첫 화면 다음부터 위계가 사라진다
- [ ] 제목의 마지막 줄에 한 단어만 남거나, 명사구가 두 줄로 쪼개진다
- [ ] 자간·행간을 정하지 않아 브라우저 기본값이다. 큰 제목의 글자가 벌어져 보이거나, 한글 본문의 행간이 좁아 답답하다
- [ ] 제목·본문·작은 글자에 같은 자간·행간을 써서 큰 글자는 성기고 작은 글자는 답답하다

## 아이콘·이미지

- [ ] 모든 항목 앞에 같은 아이콘 처리가 있는데, 아이콘이 항목을 구분하거나 찾는 데 도움이 되지 않는다
- [ ] 아이콘마다 파스텔 원형·사각 배경을 깔아서, 아이콘이 내용보다 먼저 보인다
- [ ] 이모지가 UI 아이콘 자리에 쓰였는데, 브랜드 톤이나 사용자 맥락에서 나온 이유가 없다
- [ ] 주제와 관계없는 3D 일러스트나 추상 그래픽이 실제 내용(제품 화면, 데이터, 사진)이 있어야 할 자리를 차지한다

## 모션

- [ ] 섹션마다 같은 등장 애니메이션이 들어가서, 내용을 보기까지 기다려야 한다
- [ ] 누를 수 없는 카드에도 호버 시 떠오르는 효과가 있어서, 무엇을 누를 수 있는지 헷갈린다
- [ ] 사용자 행동과 관계없이 반복 재생되는 애니메이션이 읽기를 방해한다
- [ ] `prefers-reduced-motion`을 고려하지 않았다

## 카피·콘텐츠

한국어 문장은 `korean-copy.md`의 검수 순서로 따로 본다. 여기서는 생성형 화면에서 특히 자주 나오는 것만 짚는다.

- [ ] 모든 섹션이 "단정하는 제목 한 줄 + 회색 설명 두 줄" 구조로 반복된다
- [ ] 히어로 제목이 추상 명사나 사물을 주어로 한 비유다 ("하루가 보고서가 됩니다", "데이터가 답합니다")
- [ ] "~하지 않습니다" 부정 단정, 셋씩 나열하는 대구, "~면 됩니다"·"~가 전부입니다"가 화면 곳곳에서 반복된다

- [ ] "Unlock", "Seamless", "Supercharge", "혁신적인", "차세대"처럼 아무 제품에나 붙는 말이 구체적인 설명 자리를 차지한다
- [ ] 기능 이름이 사용자 언어가 아니라 시스템 언어다
- [ ] 버튼만 읽어서는 누르면 무슨 일이 일어나는지 알 수 없다 ("Submit", "확인", 맥락 없는 "더 알아보기")
- [ ] 지어낸 수치, 지어낸 후기, 지어낸 고객 로고가 실제처럼 보인다
- [ ] `Feature 1/2/3`, lorem ipsum, "John Doe"가 남아 있다
- [ ] 메타 정보를 `A · B · C`로 이었는데, 항목이 많거나 성격이 달라서 무엇이 무엇인지 읽기 어렵다
- [ ] 한국어가 번역투다 ("~를 통해", "~에 대한", "당신의", "~하는 것이 가능합니다")
- [ ] 한 화면 안에서 "~합니다"와 "~해요"가 섞이거나, 버튼이 명사형과 동사형으로 섞여 있다
- [ ] 변수 자리에 "을(를)"이 그대로 보이거나, 띄어쓰기·숫자·단위 표기가 틀렸다
- [ ] 사용자가 쓰는 말이 한국어인데 굳이 영어 단어를 섞었다

## 마지막 질문

- 이 화면에서 로고와 이름을 지우면, 무엇을 위한 제품인지 알 수 있는가?
- 전혀 다른 주제로 같은 요청을 받았을 때 거의 같은 화면이 나오지 않을까?
- 기억에 남을 한 곳이 있는가? 그 한 곳 말고 나머지는 조용한가?
- 걸린 항목을 고친 이유가 "달라 보이려고"가 아니라 "이 사용자와 과업 때문에"인가?
