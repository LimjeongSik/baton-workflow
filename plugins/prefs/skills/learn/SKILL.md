# 스스로 학습하기

선호 학습은 **사용자가 시키는 일이 아니다.** Claude가 사용자의 요청과 행동을 보고 스스로 배우고, 배운 대로 하고, 그 결과로 다시 배운다. **사용자에게 묻지 않는다.** "기억해 둘까요?", "메모해 둘까요?", "이걸 선호로 기록할까요?", "앞으로도 이렇게 할까요?" 같은 질문은 하지 않는다. 신호인지, 남길지, 올릴지는 Claude와 recorder가 아래 판단 근거로 정한다. 틀린 학습은 사용자가 결과를 고칠 때 그 반응으로 바로잡힌다. 사용자가 "기억해 둬"라고 말했다면 그것도 하나의 신호(일반 지시)로 다룬다.

```
신호 모으기 → recorder가 거르고 로그에 쌓음 → 패턴이 서면 프로필 지시문으로 올림
     ↑                                                        ↓
 결과에 대한 사용자 반응  ←  다음 작업에서 프로필대로 함 (세션 훅이 learn/learned.md를 넣음)
```

신호는 **근거**일 뿐 그대로 지시문이 되지 않는다. 이 프로젝트의 여러 작업에서 같은 방향이 확인된 것만 프로필에 올라간다. 학습 파일은 **프로젝트 루트의 `learn/`** 에만 두고(프로젝트 루트는 세션 훅이 알려 준 경로, 곧 Claude를 실행한 폴더다. 모노레포에서 `frontend/`에서 실행했으면 `frontend/learn/`), 폴더가 없으면 세션 훅이 빈 양식(`observed.md` 관찰한 신호, `learned.md` 학습한 지시문)으로 만든다. 세션 훅이 그 프로젝트의 `learn/learned.md`만 넣으므로 다음 세션부터 **그 프로젝트에만** 적용된다. 다른 프로젝트나 전역(`~/.claude`)의 학습 내용은 참고하지 않는다. 메인 에이전트는 **신호를 모아 넘기기만** 한다.

## 1. 신호를 모은다

이번 작업(마지막으로 넘긴 뒤)의 대화에서 아래를 찾는다. 남길지, 올릴지는 recorder가 판단하므로 확실하지 않아도 모은다.

- **고친 것:** 결과를 보고 사용자가 바꾸라고 한 것 (무엇을 무엇으로)
- **고른 것:** 선택지 중 고른 것과 고르지 않은 것 (디자인 방향, 라이브러리, 구현 방식)
- **거절한 것:** 사용자가 거절했거나 되돌린 제안과 이유
- **일반 지시:** "앞으로는", "항상", "이런 건 묻지 말고", "기억해 둬"
- **행동:** 같은 종류의 질문·보고에 같은 반응을 반복함, 비슷한 요청에 같은 말을 덧붙임, 매번 바로 승인하거나 건너뜀, Claude가 만든 결과를 사용자가 직접 고친 흔적
- **적용 결과:** 이번 작업에서 프로필 항목을 따랐다면, 사용자가 그 결과를 그대로 받아들였는지 고쳤는지. 받아들였으면 그 항목을 굳히는 근거가 되고, 고쳤으면 그 항목을 고치거나 지우는 근거가 된다. 학습이 맞았는지 확인하는 유일한 신호이므로 빠뜨리지 않는다

서브에이전트(구현·테스트 등)는 사용자를 보지 못하므로 신호를 모으지 않는다. 신호는 메인 에이전트만 모은다.

모은 신호가 없으면 아무것도 하지 않고 끝낸다. 보고에도 적지 않는다.

## 2. recorder에게 넘긴다

`prefs:recorder` 에이전트를 백그라운드로 띄우고 아래를 넘긴다. recorder는 대화를 보지 못하므로 신호마다 맥락을 한 줄로 붙인다.

```
오늘 날짜: YYYY-MM-DD
프로젝트 루트: <세션 훅이 알려 준 프로젝트 루트 절대 경로>
작업: <이번 작업 한 줄>
신호:
- [고친 것] 대시보드 목업을 보고 "여백 더 넓게" → 카드 간격 16 → 24
- [행동] 세부 선택지를 묻자 이번에도 "알아서 해" (이전 작업에서도 같은 반응)
- [적용 결과] 프로필 "그림자 대신 1px 테두리"대로 했고 사용자가 고치지 않고 승인
Claude가 이번 세션에 쓴 파일: src/app/dashboard/page.tsx, ...
scrub 스크립트: <이 스킬 폴더 기준 ../../scripts/scrub.mjs의 절대 경로>
```

- 신호에 키·토큰·비밀번호 값, 이메일·전화번호 같은 개인 정보가 섞여 있으면 넘기기 전에 빼고 방식만 적는다.

- 다른 스킬이 작업을 마치며 넘긴 요약도 이 형태로 바꿔 넘긴다.
- 세션 훅이 옛 프로젝트 선호 문서(`docs/PREFERENCES.md`)가 있다고 알렸으면, 처음 넘길 때 `migrate <경로>`를 함께 넘긴다.
- 세션 훅이 옛 전역 학습 파일(`~/.claude/prefs/`)이 있다고 알렸으면, 처음 넘길 때 `migrate-global`을 함께 넘긴다.
- 세션 훅이 프로필이 길어 잘랐다고 알렸으면 `tidy`를 넘긴다.
- Agent 도구를 쓸 수 없으면 이 스킬 폴더 기준 `../../agents/recorder.md`를 읽고 그 절차대로 직접 한다.

## 3. 보고에 한 줄 적는다

recorder를 기다리지 않고 작업 보고를 먼저 한다. 결과가 오면 **프로필이 바뀌었을 때만** 한 줄로 알린다. 로그에만 남긴 신호는 알리지 않는다. 새 `[추정]`은 근거와 함께 적어, 사용자가 틀린 판단을 바로 지울 수 있게 한다. 예: "선호 학습: 작업 방식에 [추정] 세부 선택은 묻지 않고 진행 추가 (근거: 다른 작업 2곳에서 '알아서 해')".
