# AI 티 점검표

계획 단계와 구현 뒤에 각각 한 번씩 확인한다. 항목에 걸렸다고 무조건 금지는 아니다. 사용자 요청이나 레퍼런스가 그 방향을 정했다면 따른다. 다만 **근거 없이 기본값으로 나온 것**이면 바꾼다.

frontend-design 스킬이 꼽은 기본값(크림+세리프+테라코타, 검정+형광 강조, 신문형 레이아웃, SaaS 카드 키트, 대문자 eyebrow·가운뎃점·`→` 같은 템플릿 장식)도 함께 확인한다.

## 컬러

- [ ] 배경이 네이비·슬레이트·차콜 다크인데, 사용자 요청이나 분야 관례라는 근거가 없다
- [ ] 강조색이 인디고·보라·일렉트릭 블루이고, 주제에서 나온 근거가 없다
- [ ] 보라→파랑, 분홍→주황 같은 그라데이션을 장식으로 쓴다
- [ ] Tailwind 기본 팔레트 값을 그대로 쓴다 (`slate-900`, `gray-50`, `blue-500`, `indigo-600`, `emerald-500`)
- [ ] 중립색이 순수 회색이나 차가운 파란 회색이고, 주조색과 아무 관계가 없다
- [ ] 강조색이 화면 곳곳에 칠해져 있어서 강조가 강조로 보이지 않는다
- [ ] 팔레트의 각 색에 "왜 이 주제에 이 색인가"를 한 줄로 설명할 수 없다

## 레이아웃·형태

- [ ] 내용과 관계없이 모든 것이 같은 크기의 둥근 카드에 들어 있다
- [ ] 모든 요소의 모서리 반경이 같다. 위계에 따라 다르게 쓰거나 아예 각지게 쓰는 선택이 없다
- [ ] 모든 카드 아래에 같은 옅은 회색 그림자가 있다
- [ ] 3열 또는 4열의 똑같은 그리드가 반복된다
- [ ] 모든 것이 가운데 정렬이다
- [ ] 글래스모피즘(반투명 블러 패널), 네온 글로우, 장식용 블롭을 쓴다

## 타이포

- [ ] 서체를 고른 이유가 없다 (늘 쓰는 기본 산세리프 하나)
- [ ] 헤드라인에서 한 단어만 색·이탤릭·굵기로 강조한다
- [ ] 제목마다 위에 대문자 라벨(eyebrow)이 있다
- [ ] 크기 대비가 약해서 위계가 안 보인다. 모든 글자가 14~18px 사이에 몰려 있다

## 아이콘·이미지

- [ ] 모든 항목 앞에 같은 크기, 같은 스타일의 아이콘이 있다
- [ ] 아이콘마다 파스텔 원형·사각 배경을 깐다
- [ ] 이모지를 UI 아이콘 대신 쓴다
- [ ] 주제와 관계없는 3D 일러스트나 추상 그래픽을 쓴다

## 모션

- [ ] 섹션마다 페이드 인 + 위로 슬라이드가 들어간다
- [ ] 모든 카드에 호버 시 떠오르는 효과가 있다
- [ ] 사용자 행동과 관계없이 반복 재생되는 애니메이션이 있다

## 카피·콘텐츠

- [ ] "Unlock", "Seamless", "Supercharge", "혁신적인", "차세대" 같은 말이 들어간다
- [ ] 기능 이름이 사용자 언어가 아니라 시스템 언어다
- [ ] 버튼이 "Submit", "확인"처럼 결과를 말하지 않는다
- [ ] 지어낸 수치, 지어낸 후기, 지어낸 고객 로고가 있다
- [ ] `Feature 1/2/3`, lorem ipsum, "John Doe"가 남아 있다
- [ ] 메타 정보를 `A · B · C`처럼 가운뎃점으로 잇는다

## 마지막 질문

- 이 화면에서 로고와 이름을 지우면, 무엇을 위한 제품인지 알 수 있는가?
- 전혀 다른 주제로 같은 요청을 받았을 때 거의 같은 화면이 나오지 않을까?
- 기억에 남을 한 곳이 있는가? 그 한 곳 말고 나머지는 조용한가?
